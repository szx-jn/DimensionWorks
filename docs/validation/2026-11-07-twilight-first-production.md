# 暮色林地产线首版验证

2026-11-07，首版实现范围为普通森林至娜迦之前的工业起步。整合包版本同步为 `0.3.23`，Cave Factory 为 `0.1.6`。本次只提交实现，不触发正式发布或更新服务器。

## 实现范围

新增林地浸出槽、生物调理槽、林地原液及五种固体材料，共 11 个配方。沿用主世界设备与材料，树脂、纤维、框架和滤芯供暮色工艺使用。具体投入、产出、接触床、野猪工位、转速和物流规则见 [首版规格](../design/twilight-first-arrival.md#8-第一版实施规格)。

环境采集与活体作业由现有 Cave Factory 模块实现；配方、标签和流体注册放在 KubeJS。运行时不创建区块加载票据，不补算离线产量，不产生周期性掉落物。接触床每秒检查 9 个已加载方块，生物槽每秒查询局部成年野猪，每槽仅占用两只动物。

11 张原创像素贴图由 Python 标准库绘制，未调用生图模型。机器界面用 Minecraft GUI 绘制，另有 JEI 现场工艺与条件说明。

新增服务器 GameTest 覆盖：

- 使用真实 Create 动力，在真实暮色维度扣除一整批树叶、腐殖料和水并产出 1,000 mB 原液。
- 缺接触床、缺水、错误维度和原液满仓时不扣料；原液输出接口拒绝外部灌入。
- 两只成年野猪产出 4 腐殖料且保持存活；重叠工位不能同时使用同一对动物。
- 作业途中移走野猪，未完成进度归零且输入保留。
- 动物原生 `saveWithoutId` / `load` 的 ForgeData 保存休息状态，装箱期间不减少剩余休息刻，恢复后不能立即工作。
- 设施便携存储保存库存和液体，输出槽拒绝灌入物品，能力失效后可恢复。
- 真实 Create 工作盆配方匹配与应用：分离要求加热，基础与滤芯路线产物正确；框架与滤芯压块产物正确。

测试运行使用锁定的 Twilight Forest `4.3.2508`、Create `6.0.8`、KubeJS `2001.6.5-build.26`，以及清单内已有的核心运行依赖。开发运行仍沿用模块原有 Forge `47.4.16`，未更改技术基线。测试在忽略的 `run-twilight-check/` 世界内建立并加载夹具；并行检查的暮色现场区域相互隔离，不接触玩家存档。

## 验证边界

本轮没有运行完整整合包客户端，也未目视检查新机器、界面与 JEI 的游戏内显示。工作盆检查直接调用原生匹配与应用逻辑，未搭建完整机械搅拌器、压机与跨维度物流产线。

动物测试验证的是 CMP 所需的原生实体 NBT 保存路径，未实际操作 CMP 打包工具；真实打包/拆包、存档重启与区块卸载组合仍需专项试玩。机械锯不能直接视作树叶供应，自动取叶布局尚未验证。

第一版只完成林地起步。后续区域、长期净收支、实体与区块运行成本、整章 20～30 小时主动工业内容仍需继续设计与试玩，不能据此宣称整个暮色工业维度已完成。
