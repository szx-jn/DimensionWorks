# 玩家包裹与维度发运

暮色森林是 DimensionWorks 的首个探索维度。玩家不能再从原版暮色传送门进入；通路从 Create Mobile Packager 开始，经 `dw:transfer` 个人领地中的发运终端选择目的地。

## 解锁与引导

DimensionWorks RPM Limit 在齿轮之心第二项修复完成时，把永久里程碑写入玩家持久数据。转移模组检测该里程碑；旧存档也会根据 Curios 齿轮之心的修复位补记。模组记录主手 `ItemStack.save` 得到的完整物品 NBT 与快捷栏槽位，再将主手暂时替换为 `kubejs:dimension_key`。

引导完成前，服务端冻结移动、容器操作、快捷栏切换、攻击、破坏、交互、丢弃以及 CMP 连按挣脱输入，并保持玩家在启动引导的位置。只接受主手右键维度钥匙。成功进入个人物流领地后的下一服务端 tick，模组恢复原主手物品和快捷栏位置并完整同步背包；状态按玩家 UUID 保存，断线或重启后继续引导。

## 打包和物流移动

Create Mobile Packages 的 DimensionWorks 分支支持潜行并左键方块将自己打包；潜行并与其他玩家互动则可打包对方。打包玩家显示为 Create 包裹、使用矮碰撞箱并稍微减速。普通世界中，CMP 将玩家挂入 Create 传送带载客队列；链式输送的骑乘检查也把打包玩家视为有效乘客。玩家在引导锁定期间不能使用 CMP 的挣脱输入。

打包玩家进入中转领地后，可以直接钻进领地中央区块的 1×1×1 发运终端。未打包玩家仍会被方块挡住。终端使用六面不透明材质，不判定为窒息方块。终端无法破坏，且只接受本人领地、处于中转维度、已打包并在终端附近的玩家。首次靠近会显示白色提示；首次进入终端后不再显示。

打包玩家靠近设置了链式输送目标的蛙港时，服务端在有限邻域内查找已加载的蛙港与运行中链条，播放短促吸入动画后把玩家送到链上，并调用 Create 的链条骑乘同步逻辑。普通传送带输送沿用 Create 的载客运动处理。

## 服务端开销

客户端接收本人领地的 3×3 区块及外围一圈空区块渲染依赖。服务端取消玩家视距半径票据，只为九个领地区块维持临时运行票据，离开或下线立即移除；原版光照/区块状态升级仍保留边缘空区块依赖，其中紧邻的一圈发送给客户端，不创建常驻实体或保存到存档的强制加载设置。首次领地生成会先同步铺设 48×48 的站立层，地基层和边界再按每 tick 最多 4,096 次方块写入分批完成；玩家离开后生成任务暂停，区块按服务端常规规则卸载。每次 P 进入都重新寻找本人领地内的两格高安全落点，无安全落点时拒绝进入而不改动建筑。蛙港扫描只针对已打包玩家，每 5 tick 检查半径 3 格内已加载方块实体，不会主动加载扫描范围外的区块。

## 目的地

目的地列表和图像路径由 `assets/dimensionworks_transfer/dispatch/destinations.json` 提供，锁定遮罩单独加载。服务端会重新核对终端位置、玩家领地、距离、包裹状态和目的地锁定状态。

暮色终端升级卡使用 1 块 `#twilightforest:logs` 木头与任意 3 个 Boss 奖杯无序合成，允许相同奖杯重复。手持升级卡右键本人领地中央终端，消耗一张卡并永久开放 Alex 洞穴入口；重复安装不消耗。升级记录随已有领地 SavedData 保存。原生暮色冒险继续保留，新增主线只提供弹力打包工具与终端两项升级，不要求暮色全部 Boss 毕业。

| 目的地 | 发运行为 |
| --- | --- |
| 主世界 | 返回玩家绑定的有效出生点；找不到时回到主世界出生点 |
| 下界 | 依据进入中转维度前的来源坐标换算比例，搜索安全地面；不创建或站入下界门 |
| 末地 | 使用原版黑曜石平台 |
| 暮色森林 | 按需加载 TF 自身维度数据与区块，调用 `TFTeleporter.moveToSafeCoords` 并检查两格高安全空间；不生成暮色门，传统门保持拦截 |
| Alex 洞穴 | 未升级时锁定；升级后打开六个独立洞穴的图像选择页，选择后从相应真实维度寻找两格高安全落点并发运 |
| 天境 | 锁定 |

成功发运后拆包，并在玩家周围 3×3×3 范围播放彩色烟花粒子与爆炸音效。发运失败时保留包裹状态。

## 验证记录

- DimensionWorks Transfer 与 RPM Limit 均通过 Java 17 的 `clean test build`；整合包脚本单测 74 项通过，改动涉及的 JSON 和 `git diff --check` 均通过。
- CMP `0.6.1-dimensionworks.14` 的 GitHub Actions 构建和固定版本发布成功；发行 JAR 中的链条骑乘 Mixin 映射到了运行时方法名。
- Forge 专用服务器使用本次版本的 Twilight Forest `4.3.2508` 和 CMP `0.6.1-dimensionworks.14` 成功完成模组加载并输出 `Done (11.720s)`。为结束常驻服务端而发送中断后，Gradle `runServer` 以退出码 130 结束；该检查验证启动，不覆盖玩家实际交互或客户端界面显示。

新增安全与云盘约束见 [中转维度安全与云盘回收](../design/transfer-safety-cloud-disk.md)。上述历史验证记录不代表本次客户端行为已经验证。
