# 维度职责

维度不是一次性战利品区。每个维度都要在长期工业体系中承担明确职责，并通过稳定基质接入跨维度网络。

| 维度 ID | 工业职责 | 签名机 |
| --- | --- | --- |
| `alex_caves_dimensions:magnetic_caves` | 极性转换、磁通材料、充能构件与废金属重整 | 极性冶炼塔 |
| `alex_caves_dimensions:primordial_caves` | 生物质增殖、琥珀与有机材料培育 | 原生质生物反应器 |
| `alex_caves_dimensions:toxic_caves` | 核素提炼、裂变燃料前体与残渣回收 | 同位素衰变炉 |
| `alex_caves_dimensions:abyssal_chasm` | 压力萃取、珍珠壳质生长与深海材料析出 | 渊压萃取塔 |
| `alex_caves_dimensions:forlorn_hollows` | 暗相凝练、阴影材料与资源重组 | 暗相谐振器 |
| `alex_caves_dimensions:candy_cavity` | 糖晶析出、溶解/结晶转换与高密度甜品基材 | 糖晶析出器 |

## 共同约束

- 签名机只在对应维度 ID 内运行，在其他维度可放置但停转。
- 每个维度提供一条主流体主链和两类本地变体。
- 主流体必须同时消耗本地地质材料与生态、流体或生物资源。
- 每维提供数值模块和机制模块各一个；模块可跨维安装。
- 稳定基质除服务工厂内部配装外，至少接入一个整包高级组件。

## 首版状态

渊海陷窟拥有完整生存链。其余五维的核心、流体、基质、模块与残渣会注册并可在创造模式预览，但在后续里程碑前没有生存配方或实际行为。

## 自增殖循环

六个维度各自的基础产物都有一条不依赖签名机的 Create 循环，保证拿到首个环境样本后就能建立净增长库存。签名机保持预览状态，不影响这些循环提前使用。

| 维度 | 主循环载体 |
| --- | --- |
| 磁场 | Mixer 重建富铁黏液与钕材料，Compacting 压出方铅岩与充能方铅岩 |
| 原始 | Compacting 压成石灰岩，Mixer 提取树脂并培育星树果 |
| 毒化 | Mixer 造硫粉，Spout 酸蚀辐射石，Crushing Wheels 提取铀晶碎片 |
| 渊海 | 贻贝培养与 Compacting 压成渊海石，Mixer 培养生物荧光质，Sea Pig 投喂产出海雪 |
| 异寂 | Compacting 生成鸟粪与秽岩，树苗循环产出木料，Fan 出纯粹黑暗 |
| 糖果 | Press 压出冰糖，Mixer 生成明胶与紫色苏打 |

渊海陷窟的海雪是本设计唯一的实体主链：每工位最多 8 只 Sea Pig，由 Deployer 投喂 `#alexscaves:sea_pig_digests`，其余实体只作为可选加速方案。

全设计不新增任何自制生物：涉及生物的环节都只引用模组自带生物（如 Sea Pig）并做机制改动，不新增 `EntityType`、模型、动画或贴图。海猪的消化产出按原生行为掉落到世界上，收集装置由玩家自己搭建。
