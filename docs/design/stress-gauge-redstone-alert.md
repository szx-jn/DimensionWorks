# Create 应力表过载红石告警

## 目标

Create 6.0.8 的应力表监测到其动力网络过载时，从应力表方块向相邻红石系统输出 15 级红石信号；网络不再过载时撤销信号。

## 行为规格

- 只响应 Create 的应力表（`create:stressometer`），不响应速度表。
- 以 Create `StressGaugeBlockEntity` 的 `isOverStressed()` 结果作为过载依据，避免根据表盘动画或模拟值猜测状态。
- 过载时方块弱红石输出为 15，非过载、动力停转或应力机制关闭时为 0。
- 通过原版方块红石信号查询接口输出，不自制红石粉传播；粉线、比较器及中继器按原版规则衰减和更新。
- Create 重算应力网络并更新应力表时通知相邻方块更新，确保过载翻转及时传播。不得每 tick 扫描附近或全维度。
- 信号是普通方块红石输出，不强行点亮不可被弱信号供电的方块；是否需要强信号属于后续独立需求。

## 实现边界

新增 Forge 1.20.1 / Java 17 / Create 6.0.8 专用自研 Mod，使用 Mixin 扩展方块弱信号查询（只对 Create 应力表生效），并在 Create 更新应力网络账目时触发邻居通知。KubeJS 负责数据和配方，无法稳定接管该运行时状态，因此 Java 扩展是必要的。

不增加新方块、配方、物品或实体；对服务器的额外成本限于应力表状态变化时的一次邻居更新，不持续轮询。

## 验收

静态检查可确认目标类、Mixin 配置、依赖和过载状态引用一致。游戏内仍需验证：过载时相邻红石粉初始强度 15；沿红石粉每格按原版衰减；解除过载后及时熄灭；客户端/专服均能加载。
