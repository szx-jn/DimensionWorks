# 暮色收尾与 Alex 洞穴发运

2026-11-14 用户确定：暮色森林只提供弹力打包工具升级和发运终端升级，不再扩展独立工业章节或最终机械目录。本文件取代旧全章、共振、生态及机械成果草案的后续安排。

## 暮色的两个成果

- 弹力打包工具沿用现有弹跳封带制造及工具升级，不增加前置。
- 暮色终端升级卡由 **1 块暮色木头 + 任意 3 个暮色 Boss 奖杯** 无序合成。奖杯允许重复，不要求三个不同 Boss，不要求全部首领毕业。
- 木头使用固定版 Twilight Forest 的 `twilightforest:logs` 物品标签，包含八类原木、木块及其去皮版本。
- Boss 奖杯包括娜迦、巫妖、米诺菇、九头蛇、幻影骑士、暮色恶魂、雪怪首领、冰雪女王的奖杯。谜题羊属于任务奖励，不纳入击杀 Boss 奖杯。
- 此收集条件由用户直接确定，不作为齿轮之心修复碎片的工业能力考核，也不重新分配七个碎片。

## 安装与持久化

手持升级卡右键本人中转领地中央的既有发运终端，消耗一张卡，永久解锁该终端的 Alex 洞穴目的地。已经升级时不再消耗；其他玩家的终端不能安装。无需新建终端或重复科技树。

升级按玩家 UUID 写入已有领地 SavedData，与领地一起保存；死亡、重连、服务器重启以及终端恢复不撤回升级。

## 目的地 GUI 与传送

原目的地页保留 Alex 洞穴入口。未升级时显示锁定与升级提示，安装后进入独立的六洞穴选择页：磁场洞穴、原始洞穴、毒化洞穴、渊海陷窟、异寂空谷、糖果龋洞。各洞穴使用独立像素插画，可返回上一页。

服务端独立核对个人领地、终端位置、有效会话、距离、包裹状态和升级记录，客户端解锁显示不能绕过权限。六洞穴沿用 `alex_caves_dimensions` 固定版的数据与生成器，找到完整玩家高度的安全落点后传送并拆包。洞穴钥匙与天境继续沿用原限制；本次仅为合法终端发运增加当次授权。

洞穴工业内容按原有实现状态提供，本次开放旅行不代表其余五洞穴的预览工厂已经完成。

## 开销与验证

升级只在安装时写数据；GUI 开启时同步一项升级状态。不新增常驻实体、机器 tick 或持久强制加载票据。寻找落点只在发运时检查有限邻域，抵达后按原版玩家区块加载规则运行。

交付前验证重复奖杯合成、普通木头/非 Boss 奖杯拒绝、安装归属与重复安装、升级存档往返、未升级请求拒绝、六个真实维度的安全抵达，以及 GUI 图像与布局。构建和服务器 GameTest 不等同于完整多人玩法验证。
