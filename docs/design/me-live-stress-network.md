# ME 实时应力网络与两路线造价调整

## 已确认的行为边界

- 高级控制器与 ME 路线共同要求 Create 精密构件配套、AE 工程处理器与 Mekanism 强化合金生产；不绑定未定的修复碎片考核。
- 驱动器升级只消耗一台旧驱动器，并保留所装内存卡；旧代卡需另行升级至同代才能生效。四种普通卡支持同类型逐级升级，DDR5 普通卡不再消耗反物质。
- 内存卡只提供输入应力上限扣除与额外 RPM。驱动器只提供较小基础 RPM。两者都不提供 SU 储存、SU 容量或凭空生成的应力。
- 原始应力上限 S = 所有有效 IMPORT 当前贡献之和。面板沿用 Applied Create 的 SU/RPM 系数，贡献为该系数 × 当前有效转速。
- 有效应力上限 E = floor(S × (1 - loss))；卡型扣除贡献相加，默认损耗封顶 15%。
- EXPORT 按自身设定应力占额，A = 各端口 (设定系数 × 有效设定 RPM) 之和；输出运行不重复扣费，端口设定应力为零、离网或拆除释放占额，改值替换旧占额。过载时保留申请占额，避免停机释放后反复启停。
- 当 E=0 或 A>E，全网停止机械输出，显示“应力输出过载”。A=E 时正常运行，剩余额度为零。
- 全网 RPM 上限 B = 驱动器基础 RPM + 卡 RPM 贡献之和。全部有效输出设定转速 R 的和超过 B 时，全网停止机械输出，显示“输出转速过载”，不按比例降速。
- 此处“全网停运”指应力输出，AE 自身物品与流体服务继续工作。
- 为防回灌增益，IMPORT 的 Create 网络含 ME EXPORT 来源时拒绝该输入，包括跨 AE 网格回灌。

## 数值与制造

基础 RPM 依次为 DDR1～5：256、512、1024、2048、4096；每张均衡卡同序增加 256、512、1024、2048、4096 RPM。其他卡型系数与扣除贡献见对应模组 README。空驱动器可以服务小规模低速输出，卡用于提高可分配 RPM，以部分应力上限换取调速规模。旧高存储型保留注册 ID，改为低损耗型显示名。

控制器的四个粉碎轮改为四个工程处理器，四个电子管改为四个强化合金，保留八个精密构件、四个坚固板、四个黄铜机壳和原版控制器。DDR1 使用强化合金与工程处理器；后续一台旧驱动器加四个对应电路、四个合金升级。普通卡的基础材料与这条共同工业链一致。

材料来自现有矿物/化学加工与精密装配，不增加资源类型、模组或维度任务；现有跨维度物流可集中供应这些中间产品。跨维 AE 连接仍单独承担既有设施成本，不宣称这套配方自动提供跨维连接。

## 实时性、迁移与性能

AE 服务跟踪本网格的驱动器与齿轮箱参与节点，每次读取核对在线状态、模式、有效速度及配置，复杂度 O(参与节点数)。不加载区块，不增加实体，不扫描输出端下游完整机器网络。仅状态变化才刷新 Create 发电来源，使用计算重入保护。

旧 StoredSu、卡容量与 storageExponent 不再恢复或影响供能；StressKey 库存接口停用。已有实例需同步新的基础/单卡 RPM 配置，避免保留旧实例里的大基础值。

验收包括多个输入相加、输入删除/改值、持续运行不衰减、输出删除释放份额、输出改值不重复扣除、零上限全停、应力超额全停、RPM 总和超额全停、刚好用满、恢复供给自动重启、卡插拔即时改 RPM 和损耗、AE 节点离线及旧库存不能继续供能。
