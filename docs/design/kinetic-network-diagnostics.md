# 动力网络拓扑诊断

## 交互与数据

蹲下、主手持 Create 扳手（或 `forge:tools/wrenches` 标签工具），左键已加载的动力方块，取消该次破坏并打开只读网络图。无网络的动力方块仍显示自身状态。

图展示服务端采样的 source 传播树，不能把空间相邻误认为机械连接；虚拟成员单独标记，无明确 source 的成员不虚构连接。节点显示坐标、类型、理论/实际转速、个人上限、应力、容量、超载状态。网络摘要显示当前总数、已加载贡献、未加载余额及成员数，便于识别残账。读取诊断不得触发全网重算或修改保存数据。

支持拖动、缩放、点击详情、分页和手动刷新。每页最多 256 节点，按坐标/类型稳定排序，跨页 source 显示坐标。页数覆盖整个当前成员表，不静默截断。分页与刷新是新快照，网络变化后允许节点换页。

## 性能和边界

只在打开、翻页、刷新时采样；没有每 tick 全网扫描。访问已加载区块，不强制加载，不产生实体或机器。快照每个玩家最多每 10 tick 一次，需持续持扳手且处于入口方块交互距离内。独立服务端不加载 GUI 类。客户端有长度与节点数上限。

未加载区块只展示保存余额，不宣称已定位到具体未加载机器；传播树不代表所有可传动的物理边。所有读数是服务端快照，不宣称实时自动更新。

## 恢复格式与最低上限

物理成员保存独立版本标记，以及额度前的物理容量/实际应力总账和本机实际贡献；虚拟成员与数量均不混入持久化总账。`addSilently` 使用保存时的实际贡献扣账，即使动力源重启时已停止，也要扣除其原容量。恢复完成后清除浮点残差。

旧格式无法区分虚拟负载和真实未加载负载，按已加载成员重建，不假装能恢复丢失的信息；未加载旧区块正常加载后加入。保留保存的 source 图，不强行加载工厂区块。

网络最低 RPM 上限缓存随拓扑/所有者上限失效，有效转速和应力/容量统一使用；理论转速保留 Create 传播口径，低上限成员移除后无需拆机器重新恢复倍率。上限同步给客户端。SU 额度保持独立规则，样本变化后在 tick 末联动更新。

保存快照在同一网络同 tick 内复用，正常保存只扫描一次成员；影响账目的变化清除快照，避免每个方块保存都重复全网扫描。

## 节点图标与入口定位

节点色块上方叠加该机器方块对应的物品栏图标，沿用原物品模型与资源包；色块边框保留来源/虚拟/过载含义。没有对应物品的方块保留色块，不伪造替代图标。图标随画布缩放，点击区域同步调整；只发送无 NBT 的单个物品栈，不读取机器库存或强制加载区块。

首次从某个方块打开时，服务端选择包含该节点的分页，客户端选中该节点并将其定位在左侧图形画布的中心（不含右侧详情栏）。Mek 虚拟机器优先按机器坐标定位；尚未登记虚拟成员时回退到其实际接入端。手动刷新保留平移/缩放；“居中”按钮重新定位到本页入口或备用节点。节点图标更改涉及快照协议，升级协议版本，防止新旧端错读数据。
