# 稳定硫供应

## 工艺与边界

硫属于火山物料分离与基础化工资源。将下界岩、余烬面粉设定为含单质硫的火山物料，参考硫约 115℃熔融后分离的原理；该物料组成和产量属于游戏抽象，不表示现实中的所有火山岩都含可开采硫，也不模拟精确温度或逐项杂质处理。

| 工序 | 配方 |
|---|---|
| Create 粉碎轮 | 沿用下界岩粉碎配方，期望 4.48 个余烬面粉 |
| 工作盆压块回流 | 沿用 4 个余烬面粉 → 1 个下界岩 |
| 工作盆普通加热搅拌 | 4 个余烬面粉 → 1 个粗硫 |
| Create 磨石 | 1 个粗硫 → 1 个 Mekanism 硫粉，固定产出 |

普通加热需求沿用 Create 语义，超级加热也能加工，但不增加产量。热分离用四个独立输入条目，确保实际消耗四份面粉。粗硫复用原版粗金纹理，提供中英文名称与说明，新增物品需完整重启加载。

先保留母料回流，再分配剩余面粉。每次下界岩粉碎期望净余 0.48 个面粉，长期平均约 8.33 次粉碎净产一份硫。此数值不包含燃料、机器速度和停机时间，不保证单次或小批次收益；应留库存应对概率波动。红石与硫共享面粉，需要按需求分流。

## 旧配方与兼容

依据 manifest 固定的 Mekanism 10.4.16.80 实际 JAR 数据，移除三条原生配方：

- `mekanism:reaction/coal_gasification/coals`
- `mekanism:reaction/coal_gasification/dusts_coals`
- `mekanism:reaction/coal_gasification/blocks_coals`

覆盖煤炭、木炭、粉与储存块，避免其他形态绕过。保留原生火药注入氯化氢制硫；毒化洞穴制硫与残渣备链保留，后者仍受残渣生存来源限制。

合并 `forge:dusts/sulfur` 标签，包含 `mekanism:dust_sulfur` 和 `alexscaves:sulfur_dust`。整合包硫化氢和铀精矿输入接受此标签。新线输出 Mekanism 硫粉；旧洞穴配方的输出不替换，避免破坏现有精确物品任务。本次不实现锌的新循环。

## 物流与性能

下界岩属于下界物料，生产可接入既有跨维物品物流；本线没有专用跨维传输或强制维度运行限制。初期使用一套粉碎回流与一套搅拌、磨石设备，按实际吞吐扩展。通过漏斗、管道或封闭库存供料，优先保证回流并批量缓冲；不依赖地面物品堆积，不新增 BlockEntity、世界扫描或自研 tick。仅加载生产与必要物流区块，卸载时沿用机器原有暂停行为。

游戏内仍需完整重启后核对 JEI、新物品贴图、四份面粉扣料、固定研磨产出、三种煤质形态入口消失、火药制硫保留，以及两种硫粉在硫化氢和铀精矿配方中的互用。随后验证母料优先回流与长期连续供料。
