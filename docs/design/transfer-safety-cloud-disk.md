# 中转维度安全与云盘回收

## 行为约束

- 普通 P 传送不改玩家物品；一次性钥匙引导在传送完成后的服务端 tick 恢复原槽位与完整物品 NBT，并完整同步背包。消费钥匙只操作右键开始时捕获的钥匙堆叠，不能消费传送后恢复的物品。
- 中转落点先在本人领地内查找。脚部、头部必须有连续两格无碰撞、无流体空间，脚下有完整支撑；脚下至头顶的方块均不得是火、岩浆、尖刺、仙人掌、危险植物、传送门等危险方块。没有安全落点时拒绝传送并保留来源位置与物品，不破坏玩家建筑。
- 终端保留普通玩家的碰撞，包裹可以进入；终端不判定为窒息方块。模型覆盖六个方向并使用确定的实体轮廓，不能依赖完整立方体的默认遮挡推断。
- 下界直接搜索安全地面落点，不创建或站入下界门。暮色使用当前模组提供的维度数据与生物群系安全检查，按需创建缺失的 ServerLevel 并生成目的地区块，不生成暮色门。两套旧入口拦截只在服务端发运调用的作用域内放行。
- 发运落点以拆包后的两格高玩家校验；成功后清除中转返回点、拆包并同步物品。失败保留包裹与返回点。

## 领地与成本

客户端只接收本人 3×3 领地区块；在区块追踪、首次区块发送及区块更新广播入口按 UUID 检查，其他玩家领地也不可见。服务端取消中转维度的玩家视距半径票据，只对已进入玩家的九个领地区块添加临时票据，离开或下线立即移除。原版光照与区块状态升级需要边缘空区块作为内部依赖，这些空区块不发送给客户端，也不安排领地外机器运行；不能把渲染限制说成服务端完全没有依赖区块。

领地生成任务只在主人在线且位于中转维度时继续，离开暂停，服务器结束清理队列。不增加常驻实体，不保存强制加载设置。落点搜索有固定半径/高度范围，领地只读取九个已准备区块，目的地按有界邻域生成。

## 青蛙吞吐玩家的状态约束

- 中转维度外的玩家包裹可由青蛙交给运行中的 Create 锁链。吐出或取消后，对该玩家设置跨青蛙共享的 100 tick 冷却；锁链骑乘期间不允许重新吞入。
- 玩家解包后仍须运行任务清理，不能把清理入口放在包裹条件内。任务记录原维度，每次拉动前检查维度、四格距离、区块已加载、青蛙绑定和锁链连接/转速；失败先取消，不再传送。维度变化、重生、下线和服务器停止清理任务，禁止远处重新打包时恢复旧任务。
- 冷却和任务仅驻留内存；保持每五 tick 的有界附近扫描，不强制加载区块，不创建运输实体，已在冷却或骑乘的玩家不扫描。

## 云盘

最后一个频道端点消失后，库存物质球与退还升级统一写入玩家 UUID 对应的持久云盘，不自动发到背包，不生成掉落实体。在线玩家每次投递收到一条红色系统提示；离线投递在下次登录补发对应次数的提示。

F12 打开本人云盘，分页显示物品；点击或 Shift 点击领取至背包。背包空间不足时只领取可容纳部分，余量保留云盘。关闭、传送、死亡、下线或重启不领取也不丢弃云盘物品。所有领取在服务端当前菜单内检查玩家身份，客户端只提交槽位/翻页操作。

提示原文：`你有一个频道完全损坏了......，这个频道的物品已经打包成物质球发到你的云盘了，可以点击f12打开云盘界面获取物质球`

## AE2 放置限制

中转领地用于跨维物流与玩家发运，禁止新放置 AE2 及附属方块，包括创造模式、自动放置、直接写入区块、线缆与面板等部件。限制只作用于 `dw:transfer`；其他维度的生产网络与无线终端等随身物品照常使用。

按清单维护 AE2 附属命名空间，并在启动时扩展第三方对 AE2/已识别附属的必需依赖；仅有可选兼容依赖的通用模组不整体禁用。Applied Mekanistics 的 AE2 依赖为可选，但它仍属于 AE2 附属，须显式收录。整合包自研模组不因依赖 AE2 被整体禁用。数据包可通过 `dimensionworks_transfer:forbidden_transfer_blocks` 追加方块。

普通方块物品在消费前拒绝；方块写入入口拒绝新增受限方块，Forge 放置事件作为补充。存档中已有方块不扫描删除，同一种方块的状态更新与 Forge 取消操作的快照恢复保留。AE2 部件放置在修改宿主前拒绝。

Mekanism 纸箱与 CMP 打包工具共用纸箱恢复入口。允许携带和放置封装纸箱，但在解包前检查内层原方块；受限内容返回失败，保持纸箱、完整 NBT、CMP 来源标记与物品不变，不产生空纸箱。非受限内容可正常解包。操作提示使用红色文字。没有轮询区块、常驻实体或加载票据；命名空间集合启动时计算一次，写入时只做集合/标签查询。
