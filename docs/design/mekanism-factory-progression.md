# Mekanism 工厂转速与升级

机械输入按目标转速调度，原版工厂的 3 / 5 / 7 / 9 并行槽不变。默认四级目标转速均为 1024 RPM，保证同样的供料、动力和转速条件下升级不会降低产能。目标转速也决定应力系数，统一后高级机器在相同转速下按其并行数承担更高动力负载。已有实例若保留旧的自定义配置，需同步调整四项目标转速。普通无等级机器归入基础级。每次工厂升级继续保留原机器和原版 NBT 数据；9 种工厂的直接合成和等级安装器均使用同一套材料。

设实际 RPM 为 r、等级目标为 T，最高转速设计点为 10240，各级最高单次产物倍率 M 分别为 1.25 / 1.5 / 1.75 / 2。r > 0 时，工时比例 W = min(r/T, 1)，单次产物倍率 P = 1 + (M-1) × clamp((r-T)/(10240-T), 0, 1)，总理论倍率为 W × P；T ≥ 10240 时不进入超速段。无动力时为零。配置可调整 T 和 M，直接输入上限仍受现有配置与玩家 RPM 限制约束。倍率不增加槽位；在输入、输出、动力充足并且忽略整数取整时，满速理论并行产出指数依次为 3.75、7.5、12.25、18，相对基础级为 1、2、3.27、4.8。

**小数产物**：每个物品输出槽分别保存该产物的小数余量，实际成功输出时结算，模拟和容量检查不结算；不同物品、NBT 或槽位不能共享余量。例如 1.25 倍连续完成 4 次单件配方产出 5 件。余量仅在当前已加载机器对象存在时保留，不写入存档；卸载、重启或更换产物可能损失不足 1 件的余量，不会补发。气体和流体仍按每次产出向下取整。Jade 显示理论倍率；实际产量还受短时间取整、堵塞、供料和其他机器机制限制。10240 RPM 下终极级 2 倍为每次产物翻倍，输入消耗不随产物翻倍；动力负载继续按现有转速与原版机器能耗计算。

配方每级消耗 4 个相应 Mek 合金、2 个相应等级电路和 2 个 Create 部件：基础安山岩机壳、进阶黄铜机壳、精英及终极精密构件。直接合成还需要前一级机器；安装器需要木板，使用后消耗安装器。由于原版安装器可升级其他等级方块，它们也受到相同成本变化。精密构件需要 Create 精密装配，最高级还需要原子合金和终极电路。旧存档已有机器和安装器不会被追溯扣料。需在游戏中确认两种升级路径、数据保留、JEI、满速单物品与流体产量以及动力不足和输出堵塞。升级提高单方块产能，可减少同等生产规模的机器数量；模型不增加实体、区块强加载或世界扫描。
