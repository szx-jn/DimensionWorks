# 基础矿物增殖：当前配方矩阵

适用版本：Minecraft 1.20.1 Forge；Create 6.0.8；Mekanism 10.4.16.80。

## 当前设计边界

每种目标矿物暂保留两条配方：Create 机械压制、Mekanism Combiner。每条配方消耗一个目标矿物样本及各自的辅料，产出两个目标矿物。两条配方目前仍是独立路线，后续整体重规划时会改造成 Create 与 Mekanism 连续衔接的多阶段产线。

**已淘汰通用矿物残渣设计**：不再注册 `kubejs:mineral_residue`，不再通过残渣回收产矿，也不再由机械压制配方产出通用残渣。旧的 `residue_recovery` 配方 ID 不再注册。

## 配方路线

1. **Create 机械压制**：目标矿物样本与该矿物专属的固体辅料压制，产出 2 个目标矿物，不产生通用副产物。
2. **Mekanism Combiner**：目标矿物样本与对应数量的载体材料合成，产出 2 个目标矿物。副输入数量由 KubeJS Mekanism 集成按真实数量处理。

## 当前目标清单

铁、铜、锌、金、煤、红石、青金石、下界石英、紫水晶碎片、锡、铅、锇、萤石。

钻石、绿宝石、远古残骸和铀的自增配方仍暂缓，待完整产业链设计完成后再评估。

## 静态验收

- 检查脚本语法与目标列表。
- 每种目标应只注册 `mechanical_growth` 与 `mekanism_combining` 两条配方。
- 不应出现 `mineral_residue`、`residue_recovery` 或残渣物品注册。
- 游戏内仍需核对配方解码、JEI 显示、实际扣料与自动化运行；静态检查不能替代实测。
