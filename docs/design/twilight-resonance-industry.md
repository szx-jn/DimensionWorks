## 核心幻想与边界

暮色森林不是普通的“换色木材矿产维度”：树根、地下荧光、特殊树木、会改变战斗方式的首领和被进度保护的区域共同构成了一套互相关联的生态。工业的主题是**采集并稳定森林中的不同共振特征**：活根提供可再生载体，火炬浆果提供光性样本，铁木提供承载结构；再用独立的热、生命与秩序三条工艺模拟不同暮色环境。设备把这些特征转为有限时间内的战场干预与生产增益。

工业和冒险是两条可独立开始的路线，有双向可选交汇：冒险材料可以简化高级设备的生产，工业设备可以帮助实际战斗；不能免费生成 Boss 掉落、自动完成 Boss 或直接授予原生进度。工业替代品是本包新材料，只替代指定工业配方中的功能，不伪装成原版战利品或普遍替代原版装备。初次第三碎片不依赖 Boss 战利品或高级设备。允许后续个别设施有更简单的冒险配方，但必须保留不以该首领或其后续战利品为前置的工业配方。

固定 Jar 中可确认的例子：娜迦战利品表包含鳞片与奖杯，九头蛇表包含炽热之血及奖杯；活根、粗铁和金粒可合成粗铁木。暮色 Boss 类包括娜迦、巫妖、九头蛇等。具体护盾、伤害判定、分身与多部位实现尚未经运行验证；下面的效果是有待逐个核对代码和实测的产品目标，不是假称现有 API。

## 工业流程：把森林转化为可以控制的过程

下列材料均为概念名称，除标明 `twilightforest:` 的原物品外均需新增；箭头表示消耗与产出关系，不是声称已存在的配方。各支线通过不同处理条件和反馈耦合，而不是各消耗一组材料直接合成终点。

```text
暮色树苗 → 树场 → 原木/树叶 ──→ 纤维 ────────┐
火炬浆果样本 → 培育 → 浆果 ──→ 光性萃取液 ──┤
活根样本 + 纤维 + 萃取液 + 水 → 活根培育 → 活根 ─→ 原版粗铁木 → 铁木锭
                                                    │
铁木锭 + 纤维 + 萃取液 → 暮色稳相基材 ─────────────┤
                                                    ├→ 第三修复碎片
                                                    └→ 分离与校准 → 三条高级支线

生命支线：活根 + 培育液 → 活性浆 → 稳定生长膜 ─┐
热性支线：木炭 + 矿物 + 光性萃取液 → 热性浓缩物 ┤
秩序支线：铁木 + 光性萃取液 → 相位滤材 ────────┤
                                                └→ 共振组件 → 选择模块 → 功能设备
各支线的可回收残渣 → 再生处理 → 部分基础材料；仍需持续补充外部原料和动力
```

- **根系培育**：自然采集首批活根样本。设备消耗林业产物、浆果萃取液、水和动力，产出多于投入的活根，并使样本回到输入侧；必须有正的净产出，不能零消耗复制。活根也可按原配方做铁木，不改变原玩法。
- **光性萃取**：火炬浆果不只充当一个合成格。压榨产生萃取液和可用残渣，萃取液同时用于根系培育与校准，形成共享瓶颈。若原版植株不能自动再生，增加消耗生物质和水的浆果培育工艺。浆果压榨饮料等现有配方保留。
- **稳相基材**：铁木承载、纤维结构与光性萃取液稳定，产生可堆叠的基材。此处可分别采用现有 Create 混合、压制与机械合成等机制，但最终机器类型和条件须验证版本；这只是工业入门，不假装已经解释暮色全貌。
- **三路分离**：生命线重视培育液与再生物料；热性线重视供热与冷却之间的平衡；秩序线重视按批次切换、精确分流和回收滤材。它们汇合时需要缓存和按需供料：例如根系培育和校准同时争用萃取液，某线停产时必须能停止该线输入而不堵死其他线。目标是处理流量变化和恢复，而不是让玩家堆同一机器或等待更久。
- **材料循环**：滤材处理后产出失活滤材，可用生物质与水再生，损失一部分以要求补充；热性残渣可回收部分矿物，不能全额回收所有投料。先对每个循环写质量收支表并审计所有替代配方，再设置实际数量。

新增活根或铁木自动化会影响它们原有装备的获得速度；先计算原版战利品、财富、机械采掘、其他模组和压块/拆解的最便宜路线，不承诺产量平衡已经成立。除基础稳相基材外，后三支线为高级设备服务；不要求第三碎片之前完成所有高阶系统。

## 冒险捷径与工业替代

| 目标 | 冒险侧捷径（建议） | 独立工业侧 | 边界 |
| --- | --- | --- | --- |
| 稳相基材 / 第三碎片 | 可采集自然活根和浆果作为启动样本 | 树场和培育维持长期供给 | 首次不要求 Boss，不能把自然搜刮视为已证明自动化 |
| 热性浓缩物 | 炽热之血参与高效配方，减少外部燃料或加工步骤 | 用可再生的植物、普通矿物和外供能量，经过制热、淬冷和残渣处理得到工业热性浓缩物 | 只作为指定设备的等价输入，不产出炽热之血或炽铁；配方优势要实测 |
| 生命模块 | 娜迦鳞片参与一条更短的强化膜配方 | 培育活根、分离光性萃取液、压制多层生长膜并再生滤材 | 不能得到原版鳞片或冒险进度 |
| 秩序模块 | 某些结构中的非关键材料可缩短工序，具体候选待审查可达性 | 用铁木、萃取液和分离出的滤材，多次校准并回收失活滤材 | 未核实具体结构材料前不把它写进可执行配方 |
| 首领压制装置 | 打赢首领后的材料使后续生产更省步骤 | 完整三路工业链、共振组件及一次性战斗耗材 | 不要求目标 Boss 或其后续 Boss 的掉落来制造首次针对该 Boss 的设备 |

“更复杂”体现在不同物料的供给、阶段切换、回收和安全运行，而不以高额材料堆叠或极长加工时间充数。高效冒险配方与工业替代应在单位产量的材料、能耗、占地、操作及可扩展性上比较；未经测试不指定最终倍率。配方不得用宽泛标签让冒险材料无意中变成工业替代品，或让替代品被压缩、拆解转换为 Boss 战利品。

## 已取消的历史提案：共振压制桩

**目的**：为玩家创造短暂战斗窗口，让工业准备改变战斗方式，但保留 Boss、战斗和真正掉落。设备是可放置的一次性耗材；其本体由稳相基材、三路工业材料、共振组件及指定目标模块装配。初次制作不消耗任何对应 Boss 的掉落、奖杯、后续进度或第三碎片以后的专属材料。产线要从可再生来源持续生产耗材，战斗时不需要将整座工厂搬进竞技场。

**默认试验规格，待平衡**：放置后由玩家显式启动；同一台设备一次性锁定启动时选择的一个已加载、符合白名单的目标，作用半径建议 16 格，最长 60 秒。作用随距离、目标死亡、设备破坏或到期而终止。不能跨维、隔无限距离追踪或加载区块；每个 Boss 最多受一个压制桩影响，多台不能叠加或轮换刷新同一次生效窗口。60 秒只是待测基准，不是已验证最优时间。

**目标模块**（具体机制只有审查上游代码并验证能稳定实现后才可启用）：

| 模块 | 面向的暮色特征 | 试验目标 | 限制与实现审查 |
| --- | --- | --- | --- |
| 生长抑制 | 娜迦的移动与身体分段 | 给主体有限减速，使玩家更容易捕捉进攻窗口 | 不删除身体分段、不冻结 AI；核查该实体是否接受常规移速效果，不能误对每个分段叠加 |
| 光相干扰 | 巫妖战斗中的防护/投射机制 | 优先选择降低其投射物威胁或限制部分投射物，而非直接移除护盾 | 核查本版本护盾、分身和弹体归属；未验证前不承诺任何特定机制可被压制 |
| 热相屏障 | 九头蛇的火焰与多部位战斗 | 短时降低附近玩家受到的特定火焰伤害 | 作用于玩家防护而非强行修改九头蛇部位；核查伤害来源与多部位判定，不能让全部伤害归零 |

这些模块可选择先实现一个已验证的试点，不能对全部暮色 Boss 用同一个“停 AI / 关闭无敌”通用开关。实际数值与效果上限按首领原机制、多人及其他模组增益实测；其他模组 Boss 不在白名单。玩家仍需打赢并正常获得掉落和进度，设备不触发代杀奖励。设备效果属于战斗辅助，不关闭区域进度保护或授予进度。

### 生命周期与爆炸

- 启动时原子地消耗设备/内置耗材并记录目标 UUID、所属维度、开始和到期世界时间；不能通过拆除、重新放置、断电、重登或重启重置时钟或回收完整装置。未启动的设备允许取回；启动后拆除只得到失活残骸。计时以服务器游戏时间为准，不把离线墙钟时间称为游戏运行时间。
- 到期时设备在原地**爆裂并消失**，产生明显音效、粒子和短暂范围冲击；默认不破坏方块、不触发火焰、不造成物品损毁。建议只对范围内生物造成少量可配置伤害，不排除玩家；具体范围与伤害需要试验。这样保留“运行一分钟原地爆炸”的战斗风险，同时不让服务器公共建筑被机械意外摧毁。
- 有效期内提前破坏、目标死亡、目标离开范围或卸载时立即失效并不可重用；可以设计安全停机获得低价值残骸，但不能返还有效耗材或重置次数。卸载区块不主动加载；载入时根据持久化时间判定过期并至多结算一次，设备卸载期间不产生效果，不能依赖未加载区块发生爆炸。
- 失活残骸可回收部分铁木和滤材，但不能无额外投入还原原设备；必须做收支审计。效果、爆裂及战利品只在服务端执行，客户端只显示状态。多个玩家使用、目标死亡后新生成同种 Boss、保护区和服务器权限需单独验收。

**防刷新细节**：冷却挂在同一个目标 UUID 的服务端持久状态上，从首次生效开始至少持续至该次 60 秒窗口结束；桩被提前拆毁或卸载也不清除。窗口结束后允许重新使用新耗材，但不能通过同时部署多个桩叠加。需要决定是否允许长战斗分多轮辅助，默认允许，成本为每轮新装置，不宣称完全限制总战斗时长。

## 可持续设备：暮色共振增益站

增益站让稳相基材和共振组件有持续需求，不把整条产线的用途限制为修复碎片。基座可重复使用；每次开启消耗由三路材料制造的**调谐匣**，持续供能，时间到后变成失活匣。建议一个基座只装一种调谐匣，支持切换但同类型效果不叠加；未供能不运行，输入与输出满时停机且不吞料。

| 模式 | 效果目标 | 成本与限制 |
| --- | --- | --- |
| 根系调谐 | 在小范围内给予玩家与农林作业相关的增益，例如有限急迫或短时恢复 | 持续动力、生命调谐匣；不通过额外随机 tick 强制加速作物或树木 |
| 明光调谐 | 在小范围内给予夜视或有限的战斗辅助 | 光性调谐匣；不制造永久光源或绕过暮色区域进度伤害 |
| 热相调谐 | 给予有限火焰防护，适合应对火焰环境及九头蛇 | 热性调谐匣；与压制桩、药水等的叠加上限需要审查，不能成为永久无敌 |

建议 16 格内、一次 60 秒的试验档，实际范围、能耗和持续时间待完整包测试。设备仅处理自己所在已加载区块内的有限范围玩家，低频刷新状态而不逐 tick 扫描整个维度；停止、断电、卸载或拆除后已有短时效果自然过期。不得加载远端区块；同源刷新与药水/其他设备的冲突按原生效果规则及上限实测。增益站功能与压制桩不同：站是持续补给、玩家增益；桩是针对单个白名单 Boss 的一次性窗口。

## 第三碎片与依赖图

```text
普通森林样本 + 外供原料
  → 活根/浆果/林业 → 铁木 → 稳相基材 → 第三碎片 → 后续工业额度
                         └→ 三路分离 → 组件 → 压制桩/调谐匣
                                               ↓
                                       辅助实际战斗 → Boss 战利品
                                               ↓
                                    可选高效高级工业配方
```

第三碎片目前仍是精密构件经 Mek 富化，修改时必须移除其原廉价配方，并保留 ID、顺序和第三项修复后解除矿物处理额度的现有效果；旧提案的 8→64 次/秒已不适用。提议让稳相基材成为必需输入，精密构件作为技术连接件；具体组合和任务计量待审核，不能把尚未实现的关联写成现有功能。初期工厂必须能在第三项的 8 次/秒限制下启动和运行；高级生产线和压制设备不能要求第三项之后的材料才能成为唯一工业解法，或应清楚定位为第三碎片之后的可选扩展。

第三考核方向是**协调共享萃取液在培育与成品之间的分配，处理供给波动、缓冲满载与恢复**。对比第一碎片的基础生产流程，这是新的系统约束；是否与其他六项去重仍待审核。应通过实测产线的连续输出和断供恢复进行验收，现有 FTB 持有物任务不能做到，只能作为有限代理；不能将拥有一件基材、设备或碎片描述为证明自动化。

## 技术和验证边界

KubeJS 可承担配方、标签和数据；若现有模组无法支持目标 UUID 锁定、Boss 专属效果、计时与持久化、拆除防刷新和爆裂，则需要本包自研运行行为，不能以一条 KubeJS 配方假称设备已实现。先检查现有模组和 API，严格限定兼容版本，不修改第三方源码；新增专属物品进入 `dimensionworks_cave_factory:main` 创造页签。

实施前逐一验证：

1. 导出完整包注册表与生效配方；核对自然样本获取、树苗回种、浆果再生、自动化采集、铁木合成及各种交易、转换、回收循环。建立每种产物的外部投入和净产出表。

3. 按 Boss 核对具体类、护盾/分身/分段/弹体、伤害源和原生成就触发条件；测试不改变掉落、自然死亡、玩家击杀和原进度保护。机械效果仅在有稳定挂点时交付。
