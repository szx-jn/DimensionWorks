# 跨维物流接口

洞穴工厂不实现中转端口，只承诺标准物品和流体能力。端口、端口号、路由和 GUI 由后续独立规格负责。

## 工厂输出

- 稳定基质、模块、残渣和空封装是普通可堆叠物品，可由 Create 九槽包裹搬运。
- 效果流体通过 Forge 流体能力进入原生维度内的管道和储罐。
- 跨维效果流体使用 `fluid_ampoule`，最大堆叠 16，单件容量 `250 mB`。

## 封装时间戳

- 封装保存原生维度 ID 和可选的离维到期时间。
- 第一次被支持的转运路径确认离维时，整叠写入同一现实时间戳。
- 已离维的封装返回原生维度不会暂停计时。
- 到期时间为默认 60 秒，可在 COMMON 配置中调整。
- 打开、转运、灌装、机器读取或玩家携带跨维时懒结算，不执行全局库存扫描。
- 过期时恢复空瓶，并生成一份对应来源残渣。

## 防绕过边界

首版禁用原版桶，只对工厂、稳定器、封装容器和明确支持的跨维路径提供完整时限协议。第三方储罐技术上仍可能接管 Forge 流体，但不会获得额外兼容承诺。
