# 客户端指南

本指南面向准备安装和游玩 DimensionWorks 的玩家。

## 1. 官方维护平台范围

**客户端仅官方维护 Windows 和 macOS。**

Linux 客户端、移动端、ChromeOS、各类掌机系统、兼容层、云游戏环境及其他非标准客户端运行环境均不在维护范围内。即使通过自行修改、兼容层或第三方启动器成功运行，也不代表项目提供支持。

如果你在上述非支持环境中遇到安装、启动、性能、兼容性或更新问题，请自行排查；项目维护者不提供诊断、修复或适配服务，也请不要提交要求维护者处理此类环境问题的 Issue。

## 2. 确认运行环境

当前正式版基线：

| 项目 | 要求 |
| --- | --- |
| 支持的客户端操作系统 | Windows、macOS |
| Minecraft | 1.21.1 |
| 加载器 | NeoForge 21.1.267 |
| Java | 21 |
| 整合包版本 | 以 [GitHub Releases](https://github.com/szx-jn/DimensionWorks/releases) 最新正式版为准 |

请使用支持导入 Modrinth 整合包（`.mrpack`）的启动器，并确保启动器实际使用 Java 21。不要把旧版 Minecraft、Forge 实例直接改成当前版本继续使用。

## 3. 下载并安装

1. 打开 [DimensionWorks Releases](https://github.com/szx-jn/DimensionWorks/releases/latest)。
2. 在最新正式版的 Assets 中下载完整客户端包 `DimensionWorks-版本号.mrpack`。
3. 在启动器中选择导入整合包，导入下载的 `.mrpack` 文件。
4. 等待启动器下载整合包所需文件，确认实例使用 Minecraft 1.21.1、NeoForge 21.1.267 和 Java 21。
5. 首次启动前，给实例预留足够的磁盘空间和内存；具体内存分配应结合设备可用内存调整，不要把系统内存全部分配给游戏。

不同启动器的导入入口名称可能不同；请使用启动器提供的“导入整合包”或同类功能。不要将 `.mrpack` 当作普通压缩包解压后直接启动。

## 4. 首次启动与进入服务器

- 首次启动可能需要下载依赖文件，耗时取决于网络和启动器缓存情况。
- 单人游玩时，创建新世界即可开始。
- 加入多人服务器前，确认服务器使用的 DimensionWorks 版本与客户端一致，并按服主要求完成登录和认证配置。
- 如果服务器要求正版账号或指定认证服务，请按服务器公告操作；不要通过替换客户端核心文件绕过认证。

## 5. 更新整合包

更新前先确认目标版本的发行说明和下载资产。

- **首次安装或重建实例**：下载完整客户端 `.mrpack`，导入为新实例。
- **已有实例更新**：只有当对应 Release 明确提供并说明适用范围时，才使用增量更新包或项目更新器。
- **不要**把增量更新包当作完整安装包，也不要将新版本文件直接覆盖到旧版本实例。
- 更新前备份单人世界、截图、资源包和其他个人数据。重大 Minecraft 或加载器版本迁移时，优先建立全新实例；不要在唯一存档上直接试升级。

## 6. 常见问题排查

### 游戏无法启动

1. 确认启动器选择的是 Java 21，而不是系统中其他 Java 版本。
2. 确认实例版本为 Minecraft 1.21.1 / NeoForge 21.1.267。
3. 检查启动器是否完成所有文件下载，以及磁盘空间是否充足。
4. 如果仍然失败，保留完整启动日志和崩溃报告，不要只提供错误截图。

### 提示缺少 Mod 或版本不匹配

确认使用的是同一个正式版 Release 提供的完整客户端包。不要从其他整合包复制 Mod，也不要随意混用不同版本的 Mod 文件。

### 加入服务器失败

确认服务器地址、网络连通性、客户端与服务端整合包版本，以及服务器要求的账号认证方式。将错误信息和客户端日志交给服务器管理员排查。

## 7. 反馈问题

**仅受支持的 Windows 和 macOS 客户端环境可以获得项目维护者的问题排查支持。**

提交问题时，请附上：

- DimensionWorks 版本；
- Windows/macOS 版本、启动器及 Java 版本；
- 复现步骤和预期结果；
- 完整日志或崩溃报告（发布前请检查并遮蔽访问令牌、个人路径等隐私信息）。

问题反馈入口：[GitHub Issues](https://github.com/szx-jn/DimensionWorks/issues)。不受支持的平台或自行移植环境出现的问题不属于项目维护范围。
