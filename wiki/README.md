# DimensionWorks 玩家文档

这里存放面向整合包玩家、服主和服务器管理员的使用说明。本文档以实际发布包为准，优先解释如何安装、启动、更新和排查常见问题。

## 使用指南

- [客户端指南](guides/client.md)：下载、导入整合包、首次启动、更新与客户端问题排查。
- [服务端指南](guides/server.md)：部署服务端、首次启动、基础配置、备份与维护。

## 当前版本基线

当前正式版为 **0.4.12**：

- Minecraft：1.21.1
- 加载器：NeoForge 21.1.267
- Java：21

正式版下载与每个版本实际提供的文件，以 [GitHub Releases](https://github.com/szx-jn/DimensionWorks/releases) 为准。

如果指南与某个正式发行包内的说明或发行公告不一致，以对应版本的发行说明和实际包内文件为准。
