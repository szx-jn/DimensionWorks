# 成型核心与破坏核心

<Row>
  <ItemImage id="formation_core" scale="4" />

  <ItemImage id="annihilation_core" scale="4" />
</Row>

这两种核心是许多 AE2 输入和输出[设备](../ae2-mechanics/devices.md)的合成材料。它们由<ItemLink id="fluix_crystal" />和[逻辑处理器](processors.md)等材料制成。

**成型核心**与**破坏核心**本身不具备直接操作世界的功能，但可以帮助相关设备实现物品、方块等资源的输入输出。
