# DimensionWorks Version Gate

Minecraft 1.20.1 Forge 自研模组，在 Forge 登录握手阶段比较客户端与服务端实际游戏根目录的 `VERSION`。这是两端当前整合包版本的唯一依据。

- 客户端直接使用 `Minecraft.gameDirectory`，版本检测和启动本地更新器共用该目录；专用服务端使用 Forge 启动游戏目录。
- 每次登录重新读取根目录 `VERSION`，不从签名状态、更新清单、启动器版本名、模组版本、JAR 或其他目录推断版本。
- 文件为 UTF-8 编码、最多 64 字节的普通文件；支持开头的 UTF-8 BOM、首尾空格/制表符和 LF/CRLF。版本严格使用 `x.x.x`，禁止前缀、前导零和后缀，每段最大 `2147483647`。
- 读取失败显示「无法读取」并记录实际路径和原因，不将失败伪装为 `0.0.0`。文件明确写入 `0.0.0` 时才按该真实版本比较。两端文件无效时显示对应错误并关闭自动更新入口，修复文件后重新登录。

- 客户端版本过低时，在进入世界前断开登录，并显示当前版本和服务端版本。
- 点击「立即更新」后，只查找游戏根目录中的本地客户端更新器，在独立终端中传入服务端目标 `--release vX.Y.Z`。本模组不下载或替换更新器。
- Windows amd64 使用 PowerShell 新窗口，macOS arm64 使用 Terminal。Linux 仅提供服务端更新器，客户端自动更新入口显示不支持提示；其他系统或架构也显示不支持提示。
- 收到终端就绪标记后，正常关闭当前 Minecraft；交接程序等待该游戏 PID 退出后才运行更新器，最长等待 120 秒，不终止其他 Java 或启动器进程。
- 更新器缺失、终端不可用或启动失败时，保留游戏界面并显示原因。点击「暂不更新」返回标题界面。

客户端与服务端都需要安装本模组。更新器作为 GitHub Release 的独立资产分发，使用此入口前需要将对应平台的客户端更新器放入游戏根目录。交接文件使用 `.dimensionworks-update/handoff`，不增加游戏实体、区块加载或常驻服务端任务。

## 本地验证

使用 Java 17、Gradle 8.8 执行 `gradle build --no-daemon`。版本回归覆盖中文与空格目录、BOM/CRLF、文件错误、禁止其他目录与元数据回退、每次登录重新读取及客户端新旧版本比较。交接回归覆盖平台和架构选择、拒绝 Linux 客户端更新、本地更新器缺失、命令转义、指定 PID 等待，以及模拟终端就绪或失败时是否请求游戏退出；模拟测试不运行真实更新器，不代表 Windows/macOS 实际 Minecraft 客户端已验证。

## 更新记录

- `0.1.3`：移除 Linux 客户端更新器选择和终端启动适配，Linux 仅保留服务端更新。
- `0.1.2`：统一只读取实际游戏根目录 `VERSION`，客户端检测与更新器共用 Minecraft 游戏目录；移除未知版本的 `0.0.0` 回退，增加文件错误提示、读取路径日志和版本检测回归。
- `0.1.1`：版本过低时通过本地更新器与独立终端更新；收到终端就绪后正常退出游戏，替代自动下载更新器的旧入口。同步迁移测试接口与发布前资产检查。
