# DimensionWorks JEI & Jade Details

客户端 Forge 1.20.1 模组，为 JEI 的加工箭头添加游戏刻数，例如 `200t`（20 游戏刻 = 1 秒，按正常 TPS 计算）。不改配方、机器速度或服务器逻辑。

## 设计与范围

- 从配方读取时间，绝不把 JEI 的展示动画周期作为加工时间。支持原版烧炼、烟熏、高炉、营火、酿造，以及提供整数刻数接口的加工配方（`getCookingTime`、`getCookTime`、`getProcessingDuration`、`getDuration`、`getProcessingTime`）。第三方接口必须以游戏刻为单位。
- 机械动力读取 `getProcessingDuration()` 的正值；这是配方基础时长，实际耗时还受机器种类、转速、物品数量影响。未声明正时长的配方不伪造时间。风扇处理按其分类读取当前服务端配置 `kinetics.fanProcessingTime`，显示单组物品的基础处理时间，不套用原版熔炉时间；初始化、物品堆叠和物品传输还会增加实际等待时间。
- 农夫乐事烹饪读取 `getCookTime()`。
- Mekanism 的加压反应、反物质核合成读取配方时长；其他有固定周期的机器按 10.4.16.80 源码中的基础周期显示。每刻按吞吐量处理的机器不冒充固定时长配方。升级和整合包限速可能改变实际耗时。
- 接入 JEI 横向动画箭头、原版酿造箭头、Create 的三个 JEI 箭头，以及 Mekanism 的加工进度箭头。没有这些绘制接口的第三方自绘界面需要专门适配。
- 箭身至少容纳当前字体的高度；横向箭头保持原宽度，长数字等比例缩小以免盖住相邻物品槽。竖向箭头按文字宽度适当加粗。保留方向，显示金色循环进度，文字居中并带阴影。
- 每次绘制都用 `try/finally` 恢复配方上下文，避免不同配方之间串时间；反射接口按配方类缓存，不扫描世界、区块或机器。

JEI 是必需的客户端依赖；Jade 为可选集成，编译版本固定为清单中的 11.13.2。Create、Mekanism 和农夫乐事不新增为运行依赖。作为整合包客户端条目分发，服务端不安装此模组。仅靠 KubeJS 的配方事件无法统一改动这些第三方箭头的绘制，因此采用独立兼容模组和客户端 Mixin。

## 0.1.1：Mekanism 启动兼容修复

修复客户端初始化时 `MekanismProgressMixin` 的 `@Shadow getRelativeX` 无法解析而崩溃的问题。按清单固定的 Mekanism 10.4.16.80 类层次继承 `GuiTexturedElement`，正常调用其纹理访问器及 `GuiElement` 的相对坐标访问器，移除三个继承方法的 Shadow 声明。Mekanism 仅作为固定版本编译依赖，不加入发布 JAR，也不增加必需运行依赖。

箭头仍使用相对坐标，保留原有 JEI 刻数显示与非 JEI 界面行为；不增加区块加载、实体或服务端 tick 开销。发布后仍需实际启动客户端并打开 Mekanism JEI 配方页验收。

## 燃料消耗提示

**燃料提示仅针对 Create、声明依赖 Create 的附属，以及龙之进化。** 这项范围约束不限制上面的 JEI 配方时间覆盖。不会给原版、Mekanism、天境等设备添加燃料提示；这些模组的物品仍可以作为 Create 设备接受的燃料出现在列表中。

背包悬停使用 Forge 物品提示组件，Jade 则给世界中的对应设备添加相同基础数据。每项依次显示燃料图标及本地化名称、下方消耗量与最小有效周期、再下方变化条件，不将不同燃料与一组公共耗量分离。液体使用对应桶的物品栏图标，没有桶时显示流体纹理。燃料多时用 **Shift + 滚轮** 翻页，避免将大量可燃物挤成超长提示。Jade 最多预览两种，完整列表在背包中查看。

| 消费设备 | 数据依据与显示行为 |
| --- | --- |
| 烈焰人燃烧室 | 当前 Forge 燃料时间及 Create 普通/特殊燃料标签；特殊燃料 3200t 超级加热，之后还有 5000t 普通余热。Liquid Fuel 有效时，液体容器不再冒充固体燃料列出。 |
| 烈焰人液体燃料 | 优先读取 Liquid Fuel 的运行时燃料表；联机客户端没有该服务端表时，使用本包对应资源配置，明确标为本包默认。按补热时每 tick 扣量显示，缓存满时暂停，不能把补热速度当作永续耗油速度。 |
| 柴油引擎、大型模块化引擎、巨型柴油引擎 | 读取当前世界 `createdieselgenerators:fuel_type` 注册表中的对应引擎 `burn_rate`，不硬编码柴油种类或倍率。整数间隔显示每周期 1 mB，非整数间隔显示基础平均值；模块化引擎提示耗量乘长度。 |
| 柴油动力燃烧器 | 同一燃料注册表的 `burner_multiplier` 判定燃料；全开阀门每 10t 1 mB，红石模式每 1t 1 mB，中间开度按实际源码条件说明。 |
| 附魔工业 2.5.4b 烈焰人锻造室/附魔室 | 读取当前经验燃料数据映射，逐项显示图标与每次补充的经验量。液态经验在单次作业完成时扣除 C mB，C 由实际输入和模式决定；锻造基础准备阶段 200t，不能伪造通用的每秒固定耗量。 |
| 柴油动力打火机 | 可燃液体每次点火 1 mB；按操作消耗，不伪造固定时间周期。 |
| 柴油动力化学喷射器 | 1.3.12 每 2t 发射，每 25t 将从 NBT 重新读取的工作副本写回，实际保存扣量的重合周期为 50t；提示说明首次扣量受使用相位影响。仅列可燃液体。 |
| 蓝图炮 | 读取 `schematics.schematicannonShotsPerGunpowder`，按发射次数消耗火药；说明快速蓝图炮附属改变速度，不把发射次数当作固定时间。 |
| 列车控制器 | 说明列车燃料容器中固体燃料的基础燃烧时间，运行阶段才推进消耗。控制器本身不存放燃料。 |
| 龙之进化反应堆 | 读取同步配置 `reactorFuelUsageMultiplier`；每 tick 基础内部消耗为 `0.005 × 配置倍率`，再乘温度因子和 `1−能量饱和度`。分别折算成觉醒龙块/锭/粒（1296/144/16 内部单位），每种图标下有自己的数值。 |
| 龙之进化发电机、高级传送器 | 保留对既存/创造物品的提示，本包已移除其合成。发电机显示 NORMAL 满负荷每 tick 基础平均值，随模式和缓冲变化；高级传送器按普通传送或配置指定的闪现次数消耗末影珍珠，不虚构周期。 |

反应堆温度因子：不高于 1000℃ 为 0；1000–2000℃ 为 `(温度−1000)/1000`；2000–8000℃ 为 1；超过 8000℃ 为 `1+(温度−8000)²×0.0000025`。提示显示基础值和条件，未将客户端没有同步的实时反应堆容器数据冒充实际耗量。

核对版本为 Create 6.0.8-291、Create Diesel Generators 1.3.12、Create Liquid Fuel 2.2.0、Draconic Evolution 3.1.2.621，均来自 `manifest/mods.json` 的固定产物。其他附属的传热、蒸汽、经验流体加工不会仅因存在流体容器就被误判为燃烧燃料；没有独立燃料扣除逻辑的方块不增加提示。

`src/main/resources/assets/dimensionworks_jei_ticks/fuel_profiles.json` 是可由客户端资源包覆盖的补充接口。键为消费设备 ID，值为燃料列表；每项填写 `kind`（`item`/`fluid`）、`fuel`（燃料 ID）、`amount`、`unit`（`mB`/`B`/`个`）、`ticks`（原始有效周期）、`condition`。按操作/公式消耗的设备可以用文字 `rate` 代替数值三元组。运行时已有数据优先；补充接口同样受消费设备范围约束。修改整合包液体燃料数据时必须同步该资源文件，`scripts/check_jei_details.py` 及打包前置检查会核对一致性。服务端若自行更改未同步的 Liquid Fuel 数据，需要提供对应客户端配置；此时“本包默认”不能视为服务端实际值。

缓存仅保留物品/流体的静态展示数据，按配方/标签同步、资源包重载及切换世界失效，不扫描区块或运行中的机器。不会新增服务端 tick、区块加载或网络包。

## 验收

遵循仓库规则，禁止本地构建，构建由 GitHub Actions 正式发布工作流完成。游戏内需检查：

1. 熔炼铁锭显示 `200t`；高炉和烟熏显示配方自己的刻数；营火和酿造分别读取配方时间和单次酿造的 `400t`。
2. 修改 KubeJS 配方时长并重新载入，显示对应的新值；同页不同耗时的配方不能串值。
3. 农夫乐事烹饪、Create 粉碎/磨粉、Mekanism 基础加工与自定义反应时间正确。
4. 长数字、更换字体、GUI 缩放时，文字位于箭身内，物品槽仍可正常查看和点击。
5. 不带时间的合成配方保持原样；机器实际 GUI 不出现 JEI 时间覆盖；专用服务器包不包含此模组。
6. 悬停柴油引擎逐项看到燃料图标、名称及对应每 20t 1 mB 的基础消耗；模块化引擎有长度条件；燃烧器和打火机显示各自真实周期。
7. 烈焰人燃烧室列出本包四种自定义液体燃料和熔岩；热量缓存满时的条件明确；固体燃料不与 Liquid Fuel 接管的液体桶重复。
8. 反应堆三个燃料形态换算等价，温度/饱和度条件明确；修改服务器同步倍率后重连，提示数值相应改变。
9. 原版熔炉、Mekanism 喷气背包、天境设备等没有新增燃料提示；燃料列表翻页正常，每项耗量一直位于对应燃料下方；关闭 Jade 时背包提示仍工作。

静态检查与 Actions 构建不能代替上述游戏内验收。
